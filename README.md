# Портфолио и CV Алисы Макаренко

Статический сайт без фреймворков. Готовые страницы лежат в `docs/` — эту папку публикует GitHub Pages. Все ссылки относительные, поэтому сайт работает из любой подпапки.

```
content/copy.json    все тексты на русском и английском
content/media.json   картинки, видео, их размеры и подписи (alt)
content/site.json    публичный адрес сайта (необязательно)
content/FACTS.md     откуда взята каждая цифра
src/index.html       шаблон главной страницы
src/cv.html          шаблон CV
src/styles.css, src/cv.css, src/main.js
build.mjs            собирает docs/ из content/ и src/
scripts/pdf.mjs      печатает CV в PDF
scripts/shots.mjs    скриншоты для проверки (необязательно)
```

Страницы после сборки: `docs/index.html` (RU), `docs/en/index.html` (EN), `docs/cv/` и `docs/en/cv/` (CV для печати), PDF — `docs/cv/Alisa-Makarenko-CV-RU.pdf` и `docs/cv/Alisa-Makarenko-CV-EN.pdf`.

## Править тексты

Все тексты — в `content/copy.json`. Каждая строка записана парой:

```json
"title": { "ru": "Избранные выпуски", "en": "Selected episodes" }
```

Меняйте текст внутри кавычек, сохраните файл и пересоберите сайт (см. ниже). Неразрывные пробелы ставить вручную не нужно: сборка сама привязывает числа к словам («5 ноября», «8,2 тыс. просмотров»), короткие предлоги к следующему слову и не даёт переносить слова через дефис («AI-инструменты»). Если после правки сборка пишет об ошибке JSON, скорее всего пропущена запятая или кавычка.

Не трогайте поля `id`, `url`, `views`, `duration`, `date`: это данные, а не текст.

Любую новую цифру сначала сверьте с кабинетом платформы и допишите в `content/FACTS.md`, откуда она.

## Добавить видео

Выпуск: в `copy.json` найдите `case.episodes.items` и добавьте объект по образцу:

```json
{
  "id": "ID_с_YouTube",
  "title": { "ru": "Название. Подзаголовок", "en": "Title: Subtitle" },
  "duration": "1:02:03",
  "views": 12345,
  "views_label": { "ru": "12,3 тыс.", "en": "12.3K" },
  "date": "2026-12-01",
  "date_label": { "ru": "1 декабря 2026", "en": "Dec 1, 2026" },
  "note": { "ru": "Одна фраза о выпуске.", "en": "One line about it." }
}
```

`id` — это часть ссылки после `watch?v=`. Все выпуски из `case.episodes.items` показываются списком «Избранные выпуски» внутри свёрнутой «Статистики» (без обложек, ссылки открывают видео). Обложки `docs/assets/thumbs/ID-960.jpg` и превью `docs/assets/loops/ep-ID.mp4` нужны только выпускам, которые стоят в кейсе крупной карточкой (`case.film_proofs`, поле `media`); остальные файлы в этих папках лежат про запас.

Название пишите обычным регистром, без капслока: до первой точки — название, после — подзаголовок (в списке показывается только название).

Shorts — `case.shorts.items` (поля `id`, `title`, `duration`, `views`, `views_label`): шесть вертикальных карточек в кейсе.

## Как устроена страница

Сверху вниз: первый экран (роли, имя, текст, «Открыта к ролям», фото, четыре цифры) → «Что я умею» → «Полный цикл» (10 этапов) → кейс «Ведьмин час» (Shorts и два выпуска как доказательства) → «Вырезки из видео» → «Статистика» (свёрнута) → «Что пишут зрители» (свёрнуто) → контакты. Правило: каждая цифра на открытой странице встречается один раз; подробности уходят в свёрнутые блоки.

- **Первый экран** — `hero` в `copy.json`: `roles` (три роли; на русской странице английское название стоит над русским), `tagline`, `positioning`, `results`, `open_to`, `numbers`.
- **Навыки** — `skills.groups` (пять колонок) и `skills.kit` (программы, AI, оборудование).
- **Этапы** — `process.steps`. У этапа могут быть `text`, `bullets`, `tools` и `proof` — свёрнутые скриншоты под этапом: `{ "label": {…}, "items": ["script-dreams", …] }`. Ключи `items` — из блока `evidence` (там файл, заголовок и подпись). Сейчас: рабочее пространство Notion под «Планированием», три сценария под «Концепцией и сценарием», превью выпусков под «Публикацией».
- **Кейс** — `case.intro`, `case.shorts_proof`, `case.film_proofs`.
- **Вырезки** — `moments.items`; файлы и точки входа/выхода — в `media.json` (`moment-…`). Сейчас четыре: Годрикова Впадина, шоураннер (сериал HBO), патронусы и «почему именно эта тема» (хэллоуинский выпуск, без фраз о перерыве). Две запасные нарезки (`eleven-schools`, `snape-prophecy`) лежат в `docs/assets/moments/` и подключаются одной строкой.
- **Статистика** — всё в блоке `stats` в `copy.json`: `platforms` (таблица «Цифры по платформам»: строки с `"key": true` стоят в таблице, остальные — в «Все цифры по платформам»), `growth` (28 дней вокруг хэллоуинского выпуска), `audience`, `community` (Boosty и Telegram — только здесь), `files` (скриншоты кабинетов, ключи из `evidence`). Блок закрыт по умолчанию и открывается сам по ссылке «Статистика» в меню или по адресу `…#stats`.
- **Отзывы** — `voices.items`: настоящие комментарии с YouTube (поле `comment_id` — номер оригинала, `who`: `f` — пишет в женском роде, `m` — в мужском, `n` — не видно). Имён и аватаров нет, правились только опечатки и знаки, сокращения отмечены «…». Комментарии с именем соведущей не берём.
- Скриншот сценария «Сновидения» собран из `source/disk-ascii/notion-scripts-1.png` скриптом `node scripts/redact.mjs`: строка про анонс сообщества вырезана, личная заметка у «ТЕОРИЯ ПРО СОН ГАРРИ» закрыта.

Цвета блоков задаются классами `band--brown`, `band--rose`, `band--cream` в `src/index.html`; у каждого фона свои оттенки текста в `src/styles.css`, контраст текста не ниже 4,5:1.

## Заменить фото на первом экране

Фото — один файл: `docs/assets/portrait.jpg`. Положите новый снимок под тем же именем и запустите `node build.mjs`. Лучше всего подходит вертикальный кадр (около 1000×1200 px и больше) на тёмном или чёрном фоне: края фото растворяются в фоне страницы, так что прямоугольника не видно; снимок на светлом фоне тоже встанет, просто с мягкой светлой виньеткой. Если файла нет, первый экран обходится без фото.

`docs/assets/photo.jpg` — другой, необязательный файл: портрет для CV и для блока «Обо мне» на сайте видеографа. Сейчас его нет, и CV выходят без фото.

## Собрать сайт

Нужен Node.js 18 или новее.

```
node build.mjs
```

Сборка пишет предупреждения, если чего-то не хватает: текста, картинки или PDF.

## Обновить PDF

После любых правок CV (раздел `cv` в `copy.json`):

```
npm install                        # один раз
npx playwright install chromium    # один раз, если Chromium ещё не скачан
node build.mjs
node scripts/pdf.mjs
```

Скрипт проверяет, что каждое CV занимает ровно одну страницу A4. Если текст не помещается, он сообщит об ошибке: сократите пункты в `cv.experience` или `cv.summary`.

## Картинки и PDF

`docs/assets/` — исходники картинок и видео сайта, храните их, не удаляйте папку: без неё сборка остановится с ошибкой. Снимок Notion с размытой строкой «Пароли и ссылки» пересобирает `node scripts/redact.mjs`. Фон первого экрана и картинки для превью ссылок (`og.jpg`) пересобирает `node scripts/hero.mjs` (нужны ffmpeg и cwebp). Перед отправкой PDF проверьте, что в `content/site.json` заполнен `base_url`: без него в CV нет ссылки на портфолио.

Шрифты в PDF встраиваются как Type 3 (так Chrome печатает переменные шрифты Google Fonts). Текст при этом выделяется и копируется. Если нужен PDF со шрифтами TrueType, положите статические файлы Cormorant и Golos Text (.ttf или .woff2) в `docs/assets/fonts/` и подключите их в `src/cv.css` через `@font-face`.

## Посмотреть локально

```
python3 -m http.server 8080 --directory docs
```

Откройте http://localhost:8080/ (английская версия — http://localhost:8080/en/). Остановить сервер: Ctrl+C.

## Опубликовать на GitHub Pages

В настройках репозитория: Settings → Pages → Branch `main`, папка `/docs`. Когда адрес сайта станет известен, впишите его в `content/site.json` (`"base_url": "https://…/"`) и пересоберите сайт и PDF. Тогда в превью ссылок появятся абсолютные адреса, а в CV — ссылка на портфолио.

# Второй сайт: портфолио видеографа (`docs/video/`)

Сайт-«сестра»: те же шрифты, цвета и сдержанность, но главное здесь — сами ролики. Собирается той же командой `node build.mjs` вместе с первым сайтом.

```
content/video/copy.json    все тексты второго сайта, RU и EN (как content/copy.json)
content/video/media.json   ролики, обложки, петли, кадры, шоурилы; блок "layout" — какие кадры где стоят
content/video/FACTS.md     откуда взят каждый факт
src/video/index.html       шаблон страницы, src/video/cv.html — шаблон CV
src/video/styles.css, src/video/cv.css, src/video/main.js
src/video/build.mjs        сборка второго сайта (вызывается из build.mjs)
docs/video/assets/         clips/ (ролики), posters/ (обложки), loops/ (короткие петли без звука),
                           stills/ (кадры), showreel/ (шоурил и фон первого экрана), og.jpg
```

Страницы: `docs/video/` (RU), `docs/video/en/` (EN), `docs/video/cv/` и `docs/video/en/cv/` (CV), PDF — `docs/video/cv/Alisa-Makarenko-Videographer-CV-RU.pdf` и `…-EN.pdf`. Адрес на GitHub Pages: `…/alisa-makarenko/video/`.

## Добавить ролик

Нужны ffmpeg и cwebp (`brew install ffmpeg webp`). Одна команда делает веб-версию ролика (H.264, 30 кадров/с, без звука; 1920×1080 или 1080×1920, если исходник такой, иначе его родной размер — без растягивания), обложки и две петли для наведения (маленькую и `-lg` для больших карточек) и дописывает ролик в `content/video/media.json`:

```
node scripts/add-clip.mjs ~/Movies/новый-ролик.mp4 hospitality --id glamping-morning --title-ru "Утро в глэмпинге" --title-en "Morning at a glamping site" --caption-ru "Одна фраза о ролике." --caption-en "One line about it." --alt-ru "Что видно на обложке" --alt-en "What the poster shows"
node build.mjs
```

Категории: `hospitality` (Hospitality & Tourism), `lifestyle` (Lifestyle & Places), `brands` (Brands & Products), `nature` (природа и животные). Дополнительно: `--start 2 --end 14` — взять только часть исходника (в секундах), `--poster 6` — кадр для обложки, `--loop-start 3` — откуда начинается петля, `--stacked` — ролик в её формате «три кадра друг над другом» (на телефоне такой ролик не обрезается). Тексты, которые не указаны, записываются как `TODO` — допишите их в `media.json` до публикации.

Убрать ролик, не удаляя файлы: в `media.json` у этого ролика добавьте `"show": false`. Порядок карточек в главе — порядок в `media.json`. У каждой главы своя раскладка (Hospitality — вертикальные места в ряд, как плёнка, пейзажи ниже; Lifestyle — большой ролик и узкий вертикальный рядом; Brands — широкий и высокий в паре; «Природа и животные» — широкая полоса и ряд из трёх), и она сама подстраивается под число вертикальных и горизонтальных роликов. Главное правило подборки: каждый кадр на странице встречается один раз — обложка карточки не повторяется в «Кадрах», в Instagram-блоке или рядом с «Как я снимаю».

## Кадры, шоурил, тексты

Сейчас это черновой монтаж из её роликов (на сайте так и подписано: «черновой монтаж»): 16:9 открывается предметкой при свечах и местами для отдыха (купол, кемпер, дом в дождь), вертикальный 9:16 — один полный кадр за раз, без мелких полос; в конце — карточка с именем и Telegram (`node scripts/reel-card.mjs`). Когда Алиса смонтирует свой шоурил (лучше с музыкой), замените `showreel-wide.mp4` и `showreel-vertical.mp4` файлами с теми же именами и обложками `…-poster.jpg/.webp`, затем `node build.mjs` — и уберите «черновой монтаж» из `ui.showreel_note` и `showreel.text` в `copy.json`.

## Как сайт бережёт трафик

До клика грузятся только обложки и один фоновый ролик первого экрана: около 2,8 МБ всего на компьютере и 1,4 МБ на телефоне (там свой лёгкий вертикальный ролик 540×960). Петли в карточках включаются при наведении мыши или, на телефоне, когда карточка полсекунды на экране (при быстрой прокрутке ничего не качается); одновременно играют не больше трёх, ушедшие с экрана освобождаются. Полный ролик загружается только в плеере. При «Экономии трафика» и при выключенной анимации в системе видео не грузится совсем, на первом экране остаётся кнопка «Включить».

## Быстрая загрузка видео (сайт видеографа)

У каждого ролика и шоурила есть лёгкая копия `-sd.mp4` (720p, около 1,5 Мбит/с). Плеер берёт её по умолчанию, а полный файл только на большом экране с быстрым интернетом. Ролики начинают грузиться заранее: шоурил сразу после загрузки страницы, ролик карточки, когда она подходит к экрану. Под видео есть полоска: светлая часть показывает, сколько уже загружено.

После добавления или пересборки роликов запустите `node scripts/video-sd.mjs`, затем `node build.mjs`.
